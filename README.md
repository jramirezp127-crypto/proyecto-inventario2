# Proyecto Inventario (JavaScript)

Aplicación web básica para gestionar inventario con JavaScript vanilla y `localStorage`.

## Funcionalidades
- Agregar producto (nombre, precio, stock)
- Listar productos
- Aumentar/disminuir stock
- Eliminar producto
- Persistencia en navegador (`localStorage`)

## Ejecutar
1. Abrir `index.html` en el navegador.

## Estructura
- `index.html`: interfaz
- `styles.css`: estilos
- `app.js`: lógica
